# Coral Villa de Mengíbar · Ensayo por voces

Aplicación web para ensayar: muestra la partitura y reproduce la voz elegida
(Soprano, Contralto, Tenor o Bajo) destacada sobre las demás, con cursor sincronizado,
control de tempo y repetición de compases. Se instala en el móvil y funciona sin conexión.

- `app/` — la aplicación (se publica en GitHub Pages).
- `app/partituras/` — obras en MusicXML y `lista.json` con el índice.

Para añadir una obra: exportar el MusicXML desde Escáner Musical, copiarlo en
`app/partituras/` y añadir una línea en `lista.json`.
